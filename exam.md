Чем git add отличается от git commit?
- команда git add перемещает файлы в промежучтоную зону, подготовленные для выполнения
коммита. А git commit выполняет снимок файлов в истории локального репозитория.

Что такое staging area?
- Это промежуточная зона, куда попадают файлы с текущим состоянием изменения,
 перед окончательным снимком.

Что такое branch?
- Это отдельная линия разработки, где происходят собственные коммиты.

Чем git fetch отличается от git pull?
- Команда Git fetch получает новые данные из удаленного репозитория.
 А команда git pull выполняет скачивание измнений из удаленного репозитория
 и сразу применение изменений в текущей ветке.

Чем merge отличается от rebase?
- merge выполняет слиние двух веток в одну. Команда rebase позволяет создать коммиты
на новую точку основания (нужно при работе в команде).

Что такое merge conflict и почему он возникает?
- Это событие, когда гит не знает, какой вариант обновления является правильным. 
Оно возникает, когда одна переменная в двух ветках изменена по-разному.

Чем reset отличается от revert?
- Команда revert выполняет отмену коммита новым коммитом. А команда reset в зависимости
от ключей может изменять состояние файла в истории, а также убирать коммиты.

Для чего используется .gitignore?
- Для игнорирования файлов, которые Git не нужно отслеживать.

Что делает cherry-pick?
- Он позволяет переносить коммиты из одной ветки в другую без слияния.

Для чего нужны Git tags?
- Это как ярлык, который позволяет отметить изменение в ветке.
